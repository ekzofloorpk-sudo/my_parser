# My Parser — плагин-парсер для Lampa

Плагин для [Lampa](https://github.com/yumata/lampa), который ищет раздачи через ваш собственный **Jackett**. Адрес и API-ключ вводятся прямо в настройках приложения.

> **Важно:** плагин сам по трекерам не ищет. Для его работы **обязательно нужен установленный и настроенный Jackett**. Без него поиск ничего не вернёт.

## Как это работает

```
Lampa → My Parser (плагин) → Jackett (поиск по трекерам) → выбор раздачи → TorrServer (воспроизведение)
```

- **Jackett** ищет раздачи по трекерам и отдаёт список.
- **TorrServer (MatriX)** воспроизводит выбранную раздачу. Он нужен для просмотра, но к плагину отношения не имеет и настраивается отдельно в Lampa (Настройки → TorrServer).

## Возможности

- Поиск через Jackett API (`/api/v2.0/indexers/all/results`)
- Приведение результатов к формату Lampa: название, трекер, размер, дата, сиды, пиры, magnet/ссылка
- Определение качества по названию (2160p, 1080p, 720p, 480p)
- Сортировка по количеству сидов
- Если адрес или ключ не заданы, используется штатный парсер Lampa

## Шаг 1. Установка Jackett

Jackett — отдельная бесплатная программа. Скачайте её с официальной страницы релизов: <https://github.com/Jackett/Jackett/releases>

**Windows**
1. Скачайте `Jackett.Installer.Windows.exe` и установите.
2. Jackett запустится как служба, а в трее появится значок.
3. Откройте веб-интерфейс: <http://localhost:9117>

**Linux / macOS**
1. Скачайте архив под свою систему со страницы релизов.
2. Распакуйте и запустите `jackett`.
3. Откройте <http://localhost:9117>

**Docker**
```bash
docker run -d \
  --name=jackett \
  -p 9117:9117 \
  -v /путь/к/конфигу:/config \
  --restart unless-stopped \
  lscr.io/linuxserver/jackett:latest
```

### Настройка Jackett

1. В веб-интерфейсе нажмите **Add indexer** и добавьте нужные трекеры. Без добавленных трекеров поиск будет пустым.
2. В правом верхнем углу скопируйте **API Key**: он понадобится плагину.
3. Если Lampa открывается на другом устройстве (телевизор, телефон), убедитесь, что Jackett доступен по сети: используйте IP-адрес компьютера или сервера, а не `localhost`, и разрешите порт 9117 в брандмауэре.

## Шаг 2. Установка плагина в Lampa

1. Откройте **Настройки → Расширения**.
2. Добавьте ссылку на плагин:
   ```
   https://raw.githubusercontent.com/ekzofloorpk-sudo/my_parser/main/my_parser.js
   ```
3. Перезапустите Lampa.

## Шаг 3. Настройка плагина

Откройте **Настройки → My Parser** и заполните два поля:

| Поле | Что вписать | Пример |
|------|-------------|--------|
| Адрес Jackett / Prowlarr | Адрес веб-интерфейса Jackett без `/` в конце | `http://192.168.1.10:9117` |
| API-ключ | Ключ из правого верхнего угла интерфейса Jackett | `abcd1234...` |

После этого откройте любой фильм и нажмите «Торренты»: поиск пойдёт через ваш Jackett.

## Возможные проблемы

**Пустая выдача**
В Jackett не добавлены трекеры, либо неверный API-ключ. Проверьте поиск в самом интерфейсе Jackett.

**Ошибка запроса / ничего не происходит**
- Проверьте адрес: он должен открываться в браузере с того устройства, где запущена Lampa.
- Если Lampa открыта по **HTTPS**, а Jackett работает по **HTTP**, браузер блокирует запрос (mixed content). Откройте Lampa по HTTP или настройте HTTPS для Jackett.
- В некоторых окружениях (веб-версия, Android TV) может понадобиться разрешить CORS на стороне Jackett.

**Ошибка в настройках (`values[name] is undefined`)**
Обновите плагин до последней версии, удалите его из «Расширений», добавьте заново и обновите страницу через Ctrl+F5.

## Совместимость

- Работает с **Jackett**. Prowlarr использует другой формат API и в текущей версии не поддерживается.
- Протестировано на веб-версии Lampa. Внутренний формат результатов может отличаться в разных сборках и форках.
